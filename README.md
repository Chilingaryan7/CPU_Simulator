📘 Project Description

This C project demonstrates a modular application structure using:
	•	A header file (header.h) for shared declarations
	•	A source library file (lib.c) that implements reusable functions
	•	A main file (main.c) that contains the program’s entry point and core logic

The project is compiled using a Makefile, which automates the build process.

⸻

🔧 Features Used
	•	Modular C structure (separation into .c and .h files)
	•	Use of custom helper functions in lib.c
	•	Makefile for easy compilation
	•	Portable code, compatible with standard C compilers (e.g., GCC)
	•	Clean build process with make clean

⸻
